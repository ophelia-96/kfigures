005 / WORK

Completed projects.

IoT & Remote Control

ESP32 Telegram PC Wake System ESP32 Telegram ▼
A remote PC power-on system triggered by a Telegram message. The ESP32 listens for the "/on" command sent to a Telegram bot — when it receives it, it wakes up the connected PC. No need to be home.
ESP32 Web-Controlled Robot Vehicle ESP32 Web UI Motor ▼
A robot vehicle driven through a browser-based HTML interface. The ESP32 hosts a web page with directional buttons — open it on any device on the same network and start driving immediately. No app required.
ESP32 Cloud Relay Communication ESP32 Cloud / IoT ▼
An IoT relay system where commands travel through the cloud — allowing the ESP32 to receive instructions from anywhere in the world, not just the local network.

AI & Creative Tools

kfigures AI Workflow 3D Printing ▼
A pipeline that transforms any character or real person into a 3D printable figure. Starting from an image, it runs through image and 3D generation models to produce a print-ready model — turning anyone into a collectible.

Software & Automation

Python Personal Assistant System Python PC Automation ▼
A desktop assistant built in Python that integrates with OBS for PC activity recording, supports remote app launching, and feeds a live security camera — a personal control center for your machine.
